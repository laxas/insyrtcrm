{# ------------------------------------------------------------------ #} {# 1. First steps #} {# ------------------------------------------------------------------ #}

1. {% trans "First steps" %}

{% blocktrans %} InsyrtCRM replaces the Google Sheet used to track B2B PR leads and customers. Every company in the system moves through a configurable pipeline of stages, from first contact to active customer or archive. {% endblocktrans %}

{% trans "Quick orientation" %}

  • {% trans "Leads" %} – {% trans "The main list of all companies. Your starting point for daily work." %}
  • {% trans "Statistics" %} – {% trans "Activity counts and pipeline summary for the team." %}
  • {% trans "Admin" %} – {% trans "Only visible to admins. Used to manage users, stages, and imports." %}

{% trans "Your role" %}

{% blocktrans %} There are three roles: Admin (full access including user management), PR-Rep (can log activities and move stages), and Read-only (view only). Your role is set by an admin. {% endblocktrans %}

2. {% trans "Lead list – filter, sort, search" %}

{% blocktrans %} The lead list (Leads in the navigation) shows all companies in the system. By default it is sorted by most recent activity. {% endblocktrans %}

{% trans "Filter field" %} {% trans "What it does" %}
{% trans "Search" %} {% trans "Full-text search across company name, domain, contact names, and activity notes." %}
{% trans "Stage" %} {% trans "Filter to a specific pipeline stage (e.g. Prospect, Active Customer)." %}

{# ------------------------------------------------------------------ #} {# 4. Logging activities #} {# ------------------------------------------------------------------ #}

4. {% trans "Logging activities" %}

{% blocktrans %} Every contact attempt — whether successful or not — should be logged as an activity. This keeps the history complete and lets the whole team see what has been done. {% endblocktrans %}

{% trans "How to log an activity" %}

  1. {% trans "Open the company's detail page." %}
  2. {% trans "Click the Activities tab." %}
  3. {% trans "Click the button for the channel you used: Phone, Email, LinkedIn, or Letter." %}
  4. {% trans "Fill in the form and click Save." %}

{% trans "Activity channels and their fields:" %}

{% trans "Channel" %} {% trans "Key fields" %} {% trans "Typical outcomes" %}
{% trans "Phone" %} {% trans "Date/time, contact, duration, note" %} {% trans "Not reached, Voicemail, Callback agreed, Interested, Not interested, Meeting scheduled" %}
Email {% trans "Date/time, subject, direction, contact, note" %} {% trans "Sent, Interested, Not interested, Meeting scheduled" %}
LinkedIn {% trans "Date/time, direction, contact, note" %} {% trans "Connected, Message sent, Comment, Reaction" %}
{% trans "Letter" %} {% trans "Date/time, contact, note" %} {% trans "Sent" %}

{% trans "Bulk letter logging" %}

{% blocktrans %} When sending letters to many leads at once: select them in the lead list, click Export for mail-merge, then use the Log letters as sent button. This creates one activity per company automatically — no need to log each one by hand. {% endblocktrans %}

{% trans "LinkedIn is manual" %}

{% blocktrans %} InsyrtCRM does not connect to LinkedIn. All LinkedIn interactions are logged manually — just like you would note a phone call. Copy the message text or key points into the Note field so the record is useful later. {% endblocktrans %}

{# ------------------------------------------------------------------ #} {# 5. Assigning a lead #} {# ------------------------------------------------------------------ #}

5. {% trans "Assigning a lead to a team member" %}

{% blocktrans %} Every company can have one Owner — the team member responsible for it. The owner is shown in the lead list and can be used as a filter. {% endblocktrans %}

{% trans "How to assign or change the owner" %}

  1. {% trans "Open the company's detail page." %}
  2. {% blocktrans %} In the company info panel (top of the page), find the Owner field and click Edit or use the inline edit control. {% endblocktrans %}
  3. {% trans "Select the team member from the dropdown." %}
  4. {% trans "Save. The change is recorded immediately." %}

{% trans "How to see only your own leads" %}

  1. {% trans "Go to the lead list." %}
  2. {% trans "In the filter bar, set Owner to your name." %}
  3. {% trans "Click Filter." %}

{% trans "How to find unassigned leads" %}

{% blocktrans %} Set the Owner filter to (unassigned) and click Filter. These companies have no responsible person yet. {% endblocktrans %}

{% blocktrans %} Note: individual activities also record which team member performed them (Performed by). This is separate from the company owner and is set automatically to the logged-in user when saving an activity. {% endblocktrans %}

{# ------------------------------------------------------------------ #} {# 6. Pipeline stages #} {# ------------------------------------------------------------------ #}

6. {% trans "Pipeline stages & transitions" %}

{% blocktrans %} Every lead is in exactly one pipeline stage at all times. Stages are configured by an admin (in the Admin area under Stages). Common stages are e.g. New, Contacted, Proposal sent, Active customer, Archive. {% endblocktrans %}

{% trans "How to move a lead to a different stage" %}

  1. {% trans "Open the company's detail page." %}
  2. {% trans "Click the Change stage button (next to the current stage label at the top)." %}
  3. {% trans "Select the new stage from the list." %}
  4. {% trans "Optionally add a comment explaining the reason." %}
  5. {% trans "Click Save." %}

{% trans "Archiving a lead" %}

{% blocktrans %} When moving to an archive stage you will see an option to reduce personal data. If checked, all contact persons are deleted and qualitative briefing text is cleared — only the company name, domain, industry, and stage history are kept. This is irreversible. Only tick it when you are sure the lead is permanently closed. {% endblocktrans %}

{% blocktrans %} Every stage move is recorded in the History tab with a timestamp, the user who made the change, and the optional comment. {% endblocktrans %}

{# ------------------------------------------------------------------ #} {# 8. Export #} {# ------------------------------------------------------------------ #}

8. {% trans "Export (CSV & mail-merge letter)" %}

{% trans "CSV export" %}

{% blocktrans %} Click CSV in the top-right of the lead list to download the currently filtered list as a spreadsheet. The CSV respects all active filters — use filters first, then export. {% endblocktrans %}

{% trans "Mail-merge letter export (Word / XLSX)" %}

  1. {% trans "In the lead list, tick the checkbox next to each company you want to write to." %}
  2. {% trans "Click Export for mail-merge in the bulk actions bar." %}
  3. {% blocktrans %} An XLSX file downloads with one row per company — ready to use as a Serienbriefquelle in Microsoft Word. {% endblocktrans %}
  4. {% blocktrans %} After printing and sending the letters, return to the lead list and click Log letters as sent. This automatically creates a Letter – Sent activity for every company in the last export. {% endblocktrans %}
